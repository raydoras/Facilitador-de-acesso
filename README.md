# Facilitador-de-acesso

O projeto é um portal de redirecionamento de fácil acesso.

O objetivo principal é permitir que usuários cheguem a formulários específicos do Google Forms através da introdução de códigos curtos num site centralizado, eliminando a necessidade de partilhar múltiplos links extensos.

Desenvolvido com interface simples e intuitiva, com as linguagens HTML, CSS E JavaScript.
